# 3-Dars: Axborot Texnologiyalari — Onlayn Test Platformasi

Tibbiyot texnikumi 1-kurs talabalari uchun Axborotning o'lchov birliklari va Sanoq sistemalari mavzulari bo'yicha tayyorlangan onlayn test sinovi platformasi.

## Imkoniyatlari:
- 40 ta savoldan tasodifiy 20 tasi tanlanadi va variantlari aralashadi.
- Bir ekranga moslashgan (Single-screen) dizayn.
- To'liq ekran (Fullscreen) majburiy rejimi.
- Cheaterlikdan himoya: skrinshot, matndan nusxa olish, o'ng tugma va tezkor tugmalar bloklangan.
- 5 ballik baholash tizimi (86%, 71%, 56%).
- Natijalar avtomatik tarzda Google Sheets jadvaliga yoziladi.
- Butunlay emojilarsiz, sifatli SVG piktogrammalar bilan bezatilgan.

## Sahifalar:
- `index.html` — Asosiy test topshirish platformasi (SPA).
- `dars.html` — O'qituvchi uchun doskaga/proyektorga chiqarib mavzuni tushuntirish qo'llanmasi.
